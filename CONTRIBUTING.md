# Contributing to MedLens

MedLens is open source and welcomes small, honest contributions.

## Ideas that help
- Add more medicines to `data/` with a source for each price
- Hindi labels and translations
- Better fuzzy matching for hard-to-read names
- Tests for `search.py`

## How to contribute
1. Fork the repo and create a branch.
2. Make a small change and commit with a clear message.
3. Open a pull request describing what you changed and why.

## Ground rules
- Never use an AI model to generate drug facts, doses or prices. All prices must come from data in this repo.
- Never commit API keys.
